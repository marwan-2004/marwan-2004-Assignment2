# marwan-2004-Assignment2

Assignment repo for assignment/1-2 (Assignment2)





C# Calculator Application



A console-based calculator application built in C#.



\## Technologies Used

\* C#

\* .NET SDK



\## Features

\* Accepts two numbers from user input.

\* Supports addition (+), subtraction (-), multiplication (\*), and division (/).

\* Handles division by zero and invalid input gracefully.

\* Allows repeated calculations without restarting.



\## How to Run

1\. Ensure .NET SDK is installed.

2\. Open terminal in the project directory.

3\. Execute `dotnet run`.
